# Blackjack Game
A simple implementation of the classic Blackjack card game using C/C++, with a focus on object-oriented design. This project includes a basic graphical user interface (GUI) for interaction. The project was carried out for the purpose of completing a course at university

## Features
+ **Single-player mode:** Play against a virtual dealer.
+ **Graphical Interface:** Basic UI implemented (based on WinForms/Windows UI framework).
+ **Card Management:** Well-structured classes for cards, decks, and hands.
+ **Interactive Gameplay:** Standard Blackjack rules such as hit, stand, and bust.
## Technologies Used
+ **C++:** Core game logic and object-oriented design.
+ **C:** Low-level operations where necessary.
+ **Windows Forms** (or other applicable frameworks): For GUI rendering.
## How to Run
1. Clone the repository:
```bash
git clone https://github.com/Materka11/Blackjack.git
cd Blackjack
```
2. Open the project in Visual Studio.
3. Build the solution (`Blackjack.sln`).
4. Run the game.
## Game Rules
+ Player starts with two cards.
+ The objective is to get as close to 21 as possible without exceeding it.
+ Players can hit to draw another card or stand to end their turn.
+ Aces are worth 1 or 11, face cards are 10, and other cards are worth their number.
